# Anonymous
Anonymous is a modern social platform for sharing thoughts, images, and videos with a sleek dark-themed interface

## Features
### User Authentication
- Email/password login and registration
- Google authentication
- Email verification

### Content Sharing
- Text posts
- Image uploads (direct or via URL)
- YouTube video embedding


### Social Interaction
- Like/unlike posts
- Comment on posts
- View engagement metrics

## Technologies Used
- React
- Material UI
- Firebase (Authentication, Firestore, Storage, Hosting, Functions)
- Express.js
